Each example includes:

- Complete, working code
- Configuration setup

## Running the Examples

To use these examples in your project:

1. Install the package using Composer
2. Copy the example code to your project
3. Adjust namespaces as needed
4. Register services in your configuration
5. Run and test

### Installation Command

```bash
composer require php-cmd/laminas-events
```
